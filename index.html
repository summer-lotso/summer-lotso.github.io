RTC / INFERENCE & EXECUTION

RTC：让新旧动作计划在同一时间轴上衔接

问题：推理期间，机器人仍在运动

固定窗口换块曾出现等待、末点保持和观测到动作激活的时间错位。新计划生成时，旧计划已执行了一部分。

实现：时间缓冲与历史前缀引导

按观测时间组织32步计划，单在途异步推理、臂手共同激活并退休过期点；将已承诺动作前缀重新编码，参与flow-matching采样引导。

验证：计划、命令与反馈分别留证

保留模型原始动作、RTC回执、受限命令和关节反馈。已接入底层真机评测；物理平滑性与成功率收益仍需同条件开关对照。

几轮代表性修改与观察+
强化掌面方向

掌面可以转正，但策略可能停在离物体较远的位置，获得姿态奖励。

加强指尖接近

指尖距离缩短时，掌面又可能转向背面；接近与姿态约束出现冲突。

细化接触与抬升门控

区分近距离几何、真实接触与对向力，减少门控被利用；严格抓取仍未稳定达成。

BUILD · BOOTSTRAP · SELECT

参考轨迹，也需要经过实验选择

从缺少完整参考开始，把轨迹构造、策略自举与可学习性验证连起来。

  1. 01 / 构造 v1
    把接近与抓取接成完整动作

    将 SPIDER 运动学接近段与 MJWP 动力学抓取／抬升段拼接，完成本体坐标、关节与直立物体的接触配准。64 帧完整轨迹经自由接触验证，正式训练使用压缩后的 22 帧参考。

  2. 02 / 策略自举
    从 PPO rollout 中提取新参考

    基于 v1 策略，在训练对象上采集 7,000 次 rollout；按持续抬升、碰桌与末态速度过滤，限额保存 1,457 条，再按动作去重选出 32 条候选。

  3. 03 / v2 的反例
    回放更强，训练却没有更好

    按固定回放选出的 jar 参考达到 36.97%，但相同 PPO 配置训练 100 轮后只有 19.43%。它未通过门禁，因此没有继续长训。

  4. 04 / 冻结 v3
    把筛选标准改为可学习性

    保持训练代码与超参数不变，四条候选先做 10 轮短训排名，前两名再从头训练 100 轮；potted meat can 达到 43.71%，通过门禁后冻结为 v3。候选与门禁阶段不访问 unseen-100。

技术细节与实验边界+

两层动作语义

xArm7＋XHand1 有 19 个驱动关节（7＋12）；主线策略在每个 episode 起始编辑参考，实际消费 18 维参数（6 维腕部位姿＋12 维手型），再执行生成的参考轨迹。

为什么改变方法

无示范 PPO 的旧规则曾得到 20/20 的数值成功，但可视化发现不合理接触。严格的人类式抓取任务未解决，后续转向示范引导。两套任务的成功率不直接横向比较。

可学习性筛选

参考筛选依次经过固定回放、10 轮短训、100 轮门控，再进行 2,000 轮完整训练。候选选择期间不访问 unseen-100。

结果适用范围

以上是仿真中的抬升与接近判定，尚不证明持续持握、抗扰动、完整放置或真实机器人迁移。可视化样本与固定评估分别统计。

两种 PPO 决策粒度

早期策略逐步输出臂手控制量；DemoGrasp 在每回合开始编辑一次参考，随后由控制器执行轨迹。策略决策步与物理仿真步分别计数。

单次编辑如何优化

当前 PPOOneStep 实现将终局成功及碰撞约束形成的回报作为 return，以 r − V(s) 构造并标准化 advantage，再进行 PPO 裁剪更新；这里没有使用多步 GAE。

训练与恢复的工程细节

跟踪策略损失、价值损失、动作噪声与任务成功率。最终训练采用 6,000 个并行环境；仅加载模型权重的 warm start 与恢复完整优化状态分别处理。
